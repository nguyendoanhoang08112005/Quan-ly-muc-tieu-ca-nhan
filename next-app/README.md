# Next.js App Migrate

App nay la codebase Next.js moi duoc dung song song voi `frontend/` va `backend/`.

Muc tieu cua giai doan nay:

- dung nen App Router
- giu workspace cu lam nguon doi chieu
- tiep tuc migrate theo playbook trong `docs/NEXTJS_FULLSTACK_MIGRATION_PLAYBOOK.md`

## Lenh can chay sau khi duoc cap quyen cai package

```bash
npm install
npm run dev
```
